Java-反射

Java反射

反射是框架设计的灵魂，使用前提：必须先拿到代表的字节码的Class，Class类用于表示.class文件（字节码）

反射概述

反射简单来说：程序在跑起来之后，还能回头去看清自己有哪些类、这些类有哪些属性和方法，并把它们调用起来——就像一份“可调用清单”

Java反射机制是在运行状态中（不是编译时），对于任意一个类，都能够知道这个类的全部信息（所有属性和方法）；也能调用任意一个对象的任意方法和属性

这种的动态获取的信息以及动态调用对象的方法的功能（边跑边查、边查边调的能力）称为java语言的反射机制

要想解剖一个类，前提是拿到它对应的class对象——所有解剖动作都是从Class对象身上调的方法

映射概述

反射怎么做到的——通过映射

映射：给xx，在程序里找一个能代表它的对象

比如在公司用人事档案代表某人，想查他，查他的档案就行，也就是他的映射

JAVA反射做的是同一件事：类里的每个成分（成员变量、方法、构造方法、包），在JVM里都有一份对应的”档案“，而这个档案本身就是一个JAVA对象。所以”解剖一个类“=从Class对象出发，把里面每个成分都取出来，变成你能拿在手里操作的对象

名词 大白话解释
类（class） “类别 / 分类”。它描述一类东西共同有什么、能做什么。它本身是个”模板/图纸”，不能直接用。
对象（object） 一个具体的、真实存在的个体。也常叫实例（instance）——“实例”就是”具体的某一个”。
实例化（instantiate） 一个动作：把”图纸”变成”实物”的过程。
属性（field，也叫字段 / 成员变量） 描述这个类 “有什么” 的数据。比如奶茶的杯量、甜度。
方法（method） 描述这个类 “能做什么” 的操作。比如奶茶”打印标签”。
构造方法（constructor） 一种特殊的方法，专门在”造对象”的那一刻自动执行，用来给对象的属性填初值。
new Java 的关键字，意思是”给我造一个新对象“。看到 new 就是”创造”。
this 类内部用来自称的词，意思是”我自己这个对象“。
重载（overload） 同一个名字、参数不同的多个方法/构造方法并存，Java 按你传的参数自动选一个。
参数（parameter） 调用时传进括号里的数据，比如 ("大杯", 3, "珍珠")。

Class.forName()

最常用的方法

前提：需要一个字符串类，随便从哪来的，有就行，然后去”档案室“查

优点：因为只要字符串，所以这个字符串可以来自各个地方——配置文件、数据库、命令行参数。程序不用在写代码时就认识Student，这才是反射”动态“的意义。

坑：字符串写错了，编译时完全不管，运行时才抛出ClassNotFoundException（查无此人）。所以代码里必须写try-catch

Class.forName("...") 的工作方式是：拿着给的这个类，去 JVM 里找对应的类，有就可以正常运行。

问题在于：这个字符串是运行时才检查的。写 Class.forName("Student")，编译器不会去查”Student 这个类存不存在”，它只是把字符串原样传进去，等运行了才真正去找

如果字符串写错了（比如 "Student123"，根本没这个类），程序运行到这一行就会崩溃，抛出 ClassNotFoundException（”找不到类”异常）

Java 有个规定：凡是可能抛出”受检异常”的方法，编译器会强制你处理它——也就是你必须写 try-catch，明确告诉程序”如果真找不到，该怎么办”，否则编译都通不过

try-catch 的结构是固定的，作用是”试着做一件事，如果出错了就兜底处理“：

从原型类中实例化对象

方法一：newInstance（要求有无参构造）

关键：newInstance() 造对象时，调用的是”无参构造器”。也就是说， Student 类必须有一个无参构造器（public Student() {}），否则会报错

这要解决的是”造对象时想传参数“的问题。 newInstance() 只能调无参构造，造出来的对象属性都是空的（name 是 null，age 是 0）。这能在造对象时顺便把参数传进去

获取类中的属性

方法一：getFields() —— 只能拿到 public 属性

先讲：Field 是什么

之前已经认识了三种”档案对象”：

  • Class —— 代表”类”的档案
  • Constructor —— 代表”构造器”的档案

现在加一个新的：

  • Field —— 代表”属性（成员变量）“的档案

比如Student 里有 name 和 age 两个属性。反射里，可以用 Field 对象去代表它们，然后读取、修改它们

getFields() 是 Class 对象上的一个方法，作用是：把这个类的所有 public 属性，一次性拿回来

返回的是一个数组 Field[]，里面装的是每一个 public 属性的档案

关键限制：

  • getFields() 只能拿到 public 属性
  • 如果是 private、或者没写修饰符（默认）的属性，它拿不到

方法二：getDeclaredFields() —— 拿到所有属性（含 private）

上一个 getFields() 只能拿 public 属性，而 getDeclaredFields() 能拿所有属性

方法 能拿到什么 拿不到什么
getFields() 只有 public 属性 private、默认、protected 属性
getDeclaredFields() 本类声明的全部属性（public/private/默认/protected 都拿） 父类继承来的属性
  • Declared 这个词是”声明“的意思。getDeclaredFields() = “拿到这个类自己声明过的所有属性”
  • 不管属性是 public 还是 private，只要是在这个类里声明的，它都能拿到

语法：

  • 第一个参数：要改哪个对象（比如之前造出来的 stu）
  • 第二个参数：改成什么值（比如 "liu"）

修改 private

改 private 属性要”撬锁”

改 public 的 name，用 getField("name") 就行，因为 public 属性是”公开”的，谁都能碰

但 private 属性（比如 private int age）是”锁起来”的：

  • 正常情况下，类外面碰不到它
  • 即使用 getDeclaredField("age") 找到了它，也不能直接改——Java 的访问检查会拦住你，抛 IllegalAccessException（非法访问异常）

要绕过这个检查，就得多加一行：setAccessible(true)，意思是”把这把锁撬开“

setAccessible(true) 是什么

  • setAccessible：设置”是否可访问”
  • true：允许访问（撬锁）
  • 作用：关闭 Java 的访问权限检查，让 private 的东西也能被读、被改

类比：private 属性 = 锁着的抽屉。setAccessible(true) = 强行把锁撬开，然后你就能打开抽屉改里面的东西

把这个类的所有 public 方法，一次性拿回来，返回 Method[] 数组

不只是自己写的方法，还包括从 Object 类继承来的那些（wait、equals、toString、hashCode 等）。所以打印出来会有一大堆

方法二：getMethod + invoke —— 按名字调用

调用 public 方法

invoke 中文意思是”调用/执行“。它的作用就是：通过反射，去执行一个方法

反射调用方法：

invoke 的两个参数：

  • 第一个参数：在哪个对象上调用（比如 stu）
  • 后面参数：方法要传的实际参数（比如 "asdf"）

getMethod("action", String.class) 是什么

和 getField("name") 对称：

  • getField("name") → 按名字找属性
  • getMethod("action", String.class) → 按名字 + 参数类型找方法

为什么要多传一个 String.class？ 因为方法可能重载（同名不同参数）。光说”action”可能有好几个 action 方法，必须用参数类型精确指定是哪一个

  • getMethod("action", String.class) → 找”名为 action、参数是 String”的那个方法
调用 private 方法
  1. getMethods()：返回所有 public 方法，包括从 Object 继承来的（wait、equals、toString 那些都会出现，所以控制台会打印一大堆）。
  2. getMethod(“action”, String.class)：按名字 + 参数类型定位某个方法。这里找的是”名为 action、参数是 String”的方法。
  3. invoke(ab, “asdf”)：调用。第一个参数是”在哪个对象上调用”，后面是实际传的参数。相当于正常写 ab.action("asdf")。
  4. private 方法：同理用 getDeclaredMethod + setAccessible(true)，再 invoke。

getConstructor + newInstance（有参构造）

首先在开头需要import java.lang.reflect.Constructor;，用到了 Constructor 这个类，它不在默认能找到的地方，而是在一个叫 java.lang.reflect 的包里，需要导入才能使用

那为什么之前用 Class、Field 不用 import？因为 Class 在 java.lang 包里，java.lang 是自动导入的，不用写 import。而 Constructor、Field、Method 这些反射相关的类，在 java.lang.reflect 包里，必须手动 import。

第 5 行：Class c = Student.class;

拿到 Student 的 Class 档案，存进 c，现在c = class Student

第 6 行：Constructor a = c.getConstructor(String.class, int.class);

这是核心，拆开讲：

  • c.getConstructor(…)：从档案 c 里，找出构造器
  • String.class, int.class：这是”线索”，告诉它”我要找参数是 String 和 int的那个构造器”
  • Constructor a：找出来的构造器，用一个 Constructor 类型的变量 a 接住。

整行意思：从 Student 档案里，找到”有参构造器”（就是 Student(String name, int age) 那个），存进 a

第 7 行：Student b = (Student) a.newInstance("liu", 18);

这是核心之二，拆开讲：

  • a.newInstance(“liu”, 18)：用拿到的构造器 a，传入实际参数造对象。"liu" 对应 String 参数，18 对应 int 参数。
  • (Student) 强转：newInstance 默认返回 Object，强转成 Student
  • Student b：用 b 接住造出来的对象

整行意思：用 a 这个构造器，传入 “liu” 和 18，造出一个 name=”liu”、age=18 的 Student 对象。

这里就是”有参构造”和”无参构造”的区别：无参是 newInstance()（括号空），有参是 newInstance("zhang", 18)（括号里填实际值）

  • 作用：关闭 Java 的访问权限检查

为什么必须有这行？ 因为 age 是 private，正常情况下 Java 不让你在类外面碰它。如果不写 setAccessible(true) 就直接 set，会抛 IllegalAccessException（非法访问异常）

f.get(s)

get是set的反向操作——读取属性值

get(s) = 读出 stu 的 age（读）

为什么用 f.get(s) 而不是 s.age？

因为 age 是 private，在类外面不能直接写 s.age 访问。所以用反射的 get 方法，配合已经撬开的锁，把值读出来。输出 99，证明 age 真的被改成 99 了

总结

一条主线：反射 = 先拿档案，再操作档案

反射的全部动作，都是围绕”档案（Class 对象）“展开的。四个阶段层层递进：

① 获取 Class 对象（入口）

一切反射的起点。三种方法，区别在”手上先有什么“：

方法 手上先有什么 特点
getClass() 对象 从对象反查它的类
类名.class 类名（写死） 最直接、最安全
Class.forName("字符串") 字符串（可变量） 唯一真正动态的

核心：forName 里的字符串可以是运行时才知道的变量，这才是反射”动态”的灵魂

② 实例化对象（用档案造实物）

拿到档案后，用档案反过来造对象：

  • newInstance() → 无参构造，返回 Object 要强转
  • getConstructor(类型...).newInstance(值...) → 有参构造，能带参数

核心对应：getConstructor(String.class, int.class) 声明类型，newInstance("zhang", 18) 传值，两者一一对应

③ 获取/修改属性（Field）

  • getField / getFields → 只拿 public
  • getDeclaredField / getDeclaredFields → 拿全部（含 private）
  • set(对象, 值) 改、get(对象) 读

核心：private 属性要 setAccessible(true) 撬锁

④ 调用方法（Method）

  • getMethod / getMethods → 只拿 public
  • getDeclaredMethod → 拿含 private
  • invoke(对象, 参数) 调用

核心：invoke(stu, "asdf") 等价于 stu.action("asdf")，private 方法同样要撬锁
