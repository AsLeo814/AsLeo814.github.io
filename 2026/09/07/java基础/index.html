类

类是用来对一个实体(对象)来进行描述的，主要描述该实体(对象)具有哪些属性(外观尺寸等)，哪些功能(用来干啥)，描述完成后计算机就可以识别了

比如想造很多自行车，类就会像一个设计图：要多少轮子、有没有车铃、车把手在哪里。

对象

对象怎么创建

创建对象得用new

Stdent s1 = new Student()

Student：对象类型，说明这是一个学生对象

s1：对象名字，方便后面使用

new Student()：真正创建一个新的 Student 对象

按照模板student，造出一个实物本体（对象），贴上一个s1的标签，方便后续使用

构造方法

举例：

构造方法名字必须和类名完全一样

类叫A，构造方法就写A()，不能写a()、getA()

没有返回值，前面什么都不写

普通方法会写 void xxx(){}

构造方法直接写 A(){}，前面不加任何返回类型

作用

A b = new A()

只要创建对象——写了 new A()、就会立刻调用A()构造方法——给新造出来的对象做初始化

默认自带的构造方法

如果写类A的时候，自己完全不写构造方法：

Java 会自己给自己加一个我看不见得构造方法

这叫默认无参构造，只要我再写任何一个构造方法，这个自带的构造方法就消失

自己写的构造方法(带初始内容)

这时执行 A b = new A()时，会自动运行A()，把这个对象的num直接设成100

若有

System.out.println(b.num);

会输出100

带参数的构造方法

现在创建对象就要给数字：
